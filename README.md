# GMGN API - Google Sheets 통합

구글 시트 A열에 컨트랙트 주소를 입력하면 GMGN API를 통해 토큰 정보를 자동으로 조회합니다.

## 추출 데이터

| 컬럼 | 항목 | 설명 |
|------|------|------|
| A | Contract Address | 입력 컬럼 |
| B | 프로젝트 이름 | 토큰/프로젝트명 |
| C | 토큰 티커 | 심볼 (예: SOL, BONK) |
| D | MC ($) | 시가총액 |
| E | FDV ($) | 완전희석가치 |
| F | 24h 거래량 ($) | 24시간 스왑 거래량 |
| G | 홀더 | 보유 지갑 수 |
| H | 유동성 ($) | 유동성 풀 총액 |
| I | 신규 홀딩 % | 신규 홀더 비율 |
| J | 체인 | 자동 감지 체인 |
| K | 조회 시각 | 데이터 갱신 시각 |

## 설치 방법

### 1. Apps Script 편집기 열기

1. 구글 시트 상단 메뉴 → **확장 프로그램 → Apps Script**

### 2. 코드 붙여넣기

1. `코드.gs` 파일의 기존 내용을 모두 삭제
2. `gmgn_sheet.gs` 파일의 내용을 전체 복사 후 붙여넣기
3. **저장** (Ctrl+S 또는 💾 버튼)

### 3. 시트로 돌아가서 새로고침

시트 새로고침 시 상단 메뉴에 **🔍 GMGN 조회** 메뉴가 생깁니다.

### 4. 헤더 초기화

**🔍 GMGN 조회 → 헤더 초기화** 를 클릭하면 헤더가 자동으로 설정됩니다.

## 사용법

### 자동 조회 (onEdit 트리거)

- **A2 이하 셀**에 컨트랙트 주소를 입력하면 자동으로 API를 호출합니다.
- 주소를 지우면 해당 행 데이터가 함께 초기화됩니다.

### 수동 조회

| 메뉴 | 기능 |
|------|------|
| 선택 행 새로고침 | 선택한 범위의 행만 다시 조회 |
| 전체 새로고침 | A열에 주소가 있는 모든 행 재조회 |

## 지원 체인

| 체인 | 주소 형식 | 자동 감지 |
|------|-----------|----------|
| **Solana** | Base58, 32~44자 | ✅ |
| **Ethereum** | `0x` + 40 hex | ✅ (EVM 기본) |
| **BSC** | `0x` + 40 hex | ✅ (EVM과 동일 포맷) |
| **Tron** | `T` 시작, 34자 | ✅ |

> BSC / Base 주소는 ETH와 형식이 동일하여 자동 구분이 어렵습니다.  
> 필요 시 코드 상단 `detectChain_()` 함수에서 기본값을 변경하세요.

## 주의사항

- GMGN API는 **Cloudflare**로 보호되어 있어 간헐적으로 차단될 수 있습니다.
- API 차단 시 `⚠️ 데이터 없음` 또는 `❌ 오류` 메시지가 표시됩니다.
- 대량 조회 시 **전체 새로고침** 메뉴 사용을 권장합니다 (행당 0.6초 딜레이 적용).
- Apps Script의 1회 실행 제한 시간은 **6분**입니다.

## 문제 해결

### "조회 중..."에서 멈추는 경우
- GMGN 서버가 Apps Script IP를 차단한 상태일 수 있습니다.
- 잠시 후 재시도하거나 **수동 실행** 버튼을 이용하세요.

### "❌ 오류" 메시지
- Apps Script 편집기 → **실행 → 실행 로그**에서 상세 오류 확인 가능합니다.
